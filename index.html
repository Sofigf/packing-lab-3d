MODEL & QUICK GUIDE

Your first commissioning session

  1. Run → Start. Run menjalankan clock; Start adalah push button lapangan. Tunggu ±10 detik simulasi untuk produk pertama keluar.
  2. Wiring. Hapus kabel Product sensor → I0.3. Produk berikutnya melewati jaw tanpa sealing. Sambungkan lagi dengan klik kedua terminal.
  3. Ladder. Edit preset T0 untuk delay berhenti, T1 untuk dwell. Edit otomatis Pause dan reset bit/timer PLC; tekan Run dan Start lagi.
  4. Eksperimen. Naikkan speed dengan T0 tetap. Amati posisi berhenti dan reject ketika produk keluar.
  5. Data. Pause, lalu unduh Data CSV, Event CSV, atau Session JSON.

3D machine view

Drag untuk memutar kamera, scroll untuk zoom, Shift + drag untuk pan. Gunakan Overview, Front, Top, atau Seal close-up. Klik komponen atau label untuk melihat status I/O aktual. Expand memperbesar workspace mesin. Guards dan Factory hanya mengubah tampilan, bukan interlock atau fisika mesin. Tombol 2D diagram menyediakan tampilan skematis alternatif.

Material, rangka, guard, pneumatic hose, panel dan lingkungan pabrik adalah visualisasi 3D edukasi. Posisi produk, belt travel, sensor, jaw, HMI dan lampu membaca engine simulasi yang sama. Model belum mencakup benturan 3D, film feeding, suhu sealing, atau dinamika pneumatik lengkap. WebGL 2 memberikan material dan shadow lengkap. Jika GPU tidak tersedia, mode Compatibility tetap merender geometri 3D dengan orbit, pan, zoom dan tekstur melalui CPU, dengan lighting sederhana dan tanpa shadow dinamis.

Physical assumptions

Conveyor sepanjang 1,100 mm; pusat jaw 600 mm; panjang produk 60 mm. Produk baru masuk di pusat x = 30 mm. Spacing adalah jarak antar pusat produk dan feed mengikuti jarak gerak belt. Tidak ada percepatan/inersia atau simulasi termal.

Sensor aktif saat badan produk melintasi beam. Response delay berlaku untuk tepi ON dan OFF. Dengan default 200 mm/s, sensor 400 mm dan delay 20 ms, T0 = 1,130 ms membawa pusat produk mendekati jaw.

Good: pusat produk saat jaw tertutup berada di 600 ± 25 mm, full-closed dwell ≥500 ms, tidak bergerak selama sealing, dan tidak terinterupsi E-stop. Capture area jaw ±100 mm; produk di luar itu tidak terseal. Hasil dihitung ketika pusat produk melewati 1,130 mm. Total completed = good + reject. Throughput = completed / simulation time × 60.

PLC & wiring

Fixed scan 10 ms. Input dibaca dari kabel; rung dievaluasi berurutan dan write bit langsung terbaca rung berikutnya; output fisik diperbarui setelah semua rung. TON reset saat rung OFF; CTU hanya menghitung rising edge dan reset melalui alamat reset-nya (default M7.7). NO membaca nilai bit, NC membaliknya. Slot kosong membuat rung selalu ON.

Model wiring hanya sinyal kontrol, tanpa arus, tegangan, kabel common, atau daya motor. Stop dan E-stop circuit menghasilkan ON saat sehat. Input diagnostic adalah alarm model, bukan fault detection ladder tersembunyi. Perubahan wiring berlaku pada scan berikutnya.

Faults & safety

Stuck ON/OFF memaksa sinyal sensor setelah response delay. Actuator late mengalikan waktu gerak jaw ×5. Jam membekukan belt dan produk. E-stop memblokir gerakan dan menghapus runtime PLC terlepas dari wiring. Release E-stop → Safety Reset → Start. Jaw dapat kembali membuka setelah reset dan Start. Ini model edukasi, bukan rancangan keselamatan mesin atau emulator vendor; tidak bisa diunggah ke PLC fisik.

Sessions

Pause membekukan waktu; Single Scan maju tepat 10 ms saat paused. 0.5×/1×/2× mengubah waktu wall-clock saja. Reset menghapus data sesi, bukan program atau wiring. Save/Load Project menyimpan konfigurasi dan selalu load dalam keadaan berhenti; Save Project tidak menyimpan data sesi. Gunakan Session JSON untuk arsip hasil. Saat tab browser tersembunyi, simulator otomatis Pause. Simpan project sebelum menutup halaman.
